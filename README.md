# 🎵 音乐小屋 · 寻声之旅

一个基于纯前端（HTML + CSS + JavaScript）的音乐探索类小游戏 Demo。玩家在随机生成的音乐小屋里寻找留声机、黑胶唱片机、八音盒和调音旋钮，播放音乐获得积分，70 秒内尽可能拿高分。

## 🎮 在线试玩

**https://onemoretimea.github.io/music-room-demo/**

手机 / 电脑浏览器直接打开即可，无需安装任何东西。

## 🕹️ 玩法说明

| 操作 | 说明 |
|---|---|
| **点击地图空地** | 火柴人移动到该位置 |
| **点击物件** | 自动走近并互动 |

### 物件一览

| 物件 | 数量 | 作用 |
|---|---|---|
| 📻 留声机 | 4 台 | 自带唱片，点击直接播放，播完加分 |
| 🎶 黑胶唱片机 | 2 台 | **背包里要有唱片才能放**，播放 AI 生成音乐（20–30 秒），播完弹音乐问答，答对额外加分 |
| 🎁 八音盒 | 1 个 | 短旋律，少量分 |
| 🎚️ 调音旋钮 | 3 个 | 集齐 3 个触发隐藏合奏 +100 分 |
| 💿 散落黑胶唱片 | 4 张 | 外观完全一样，放进唱片机才知道好坏：普通 / 彩胶 / 破损 / **假唱片陷阱** |
| ⚫ 噪音区域 | 4 个 | 灰色虚线圈，在里面放音乐音量减半、分数 ×0.6 |

### 游戏规则

- **70 秒限时**：时间到自动结算，分数越高评价越好
- **时间衰减**：越早播放分越高（系数最低保留 0.5）
- **噪音衰减**：在噪音区播放分数 ×0.6
- **完美聆听**：播放全程守在机器旁不走开，分数 ×1.2
- **假唱片陷阱**：12% 概率，会把唱片机刮坏锁死
- **通关评价**：S（≥500）/ A（≥400）/ B（≥300）/ C

## 🛠️ 技术栈

- 纯原生 HTML / CSS / JavaScript，无任何框架
- Web Audio / `<audio>` 标签播放音频
- SVG 火柴人角色
- 单文件 `index.html`（内嵌全部 JS + CSS）

## 📁 项目结构

```
music-demo/
├── index.html          # 游戏主文件（含全部逻辑）
└── assets/
    ├── phono1.wav      # 留声机音乐 1（AI 生成）
    ├── phono2.wav      # 留声机音乐 2（AI 生成）
    ├── musicbox1.wav   # 八音盒音乐（AI 生成）
    ├── vinyl1.mp4      # 黑胶 AI 音乐 1（用户上传）
    ├── vinyl2.mp4      # 黑胶 AI 音乐 2
    ├── vinyl3.mp4      # 黑胶 AI 音乐 3
    └── vinyl4.mp4      # 黑胶 AI 音乐 4
```

## 🚀 本地运行

直接双击 `index.html` 即可。如果浏览器拦截本地音频，在 `music-demo` 目录下起一个静态服务器：

```bash
# Python
python -m http.server 8000

# 然后访问
# http://localhost:8000
```

## 🔧 自定义

打开 `index.html`，搜索以下关键字即可调整：

| 搜索 | 作用 |
|---|---|
| `TIME_LIMIT = 70` | 改游戏时长（秒） |
| `QUESTIONS = [...]` | 改音乐问答题库 |
| `VINYL_TRACKS = [...]` | 替换黑胶音乐路径 |
| `rollQuality()` | 调唱片品质概率 |
| `base:60` 等数字 | 调各类物件基础分 |
| `randPos()` | 改物件随机布点逻辑 |
